# HockeyLab

An AI-powered NHL analytics platform that predicts hockey game outcomes using historical data and machine learning.

## Project Goals

- Display the NHL schedule for a selected day.
- Allow users to select any scheduled game.
- Predict home and away win probabilities.
- Compare team performance and recent results.
- Track predictions against actual game outcomes.
- Explore historical games and team statistics.

## Technology Stack

- **Language:** Python
- **Machine Learning:** Scikit-learn
- **Data Processing:** Pandas and NumPy
- **Backend:** FastAPI
- **Database:** PostgreSQL
- **Frontend:** React and TypeScript
- **Testing:** Pytest
- **Version Control:** Git and GitHub

## Project Status

Currently in development. Initial development environment and project structure are being established.
